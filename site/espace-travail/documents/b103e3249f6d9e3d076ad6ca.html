Contrôle · Sentinelle · Bump 5 m · V0.2

VERSION DE TRAVAIL — PROTOTYPE V0.2 VALIDÉ POUR PUBLICATION ; ÉQUILIBRAGE À TESTER

Peuple : Humain Classe : Sentinelle Rôle : Tank N° : 5 Compétence : Balayage du Veilleur Type : Contrôle Base / impact : 100 Coefficient : 0.20 Coût : 25 Résolution CD (s) : 30 Portée (m) : 3 PvP x : 1.0 Contrôle / mécanique : Repousse de 5 m à l’opposé du tank ; 3 ennemis maximum dans un cône frontal de 90° Puissance brute réf. : 300 Puissance PvP réf. : 300 Projection (m) : 5 Préparation (s) : 0,45 Cibles : Cône frontal de 90°, profondeur 3 m ; 3 ennemis maximum, les plus proches

Description : La Sentinelle avance d’un pas ferme et balaie l’espace devant elle avec son bouclier, repoussant les ennemis qui encombrent sa ligne. Objectif : Dégager plusieurs assaillants d’un allié ou ouvrir un passage. Quand l’utiliser : Quand plusieurs ennemis convergent devant vous vers un allié vulnérable. Synergies : Interception Héroïque vous rapproche d’un allié ; orientez ensuite le cône vers les assaillants. Garde reste soumise à sa portée de 9 m. Limites et contres : Trois ennemis maximum, projection plus courte et recharge de 30 s ; les ennemis sur les flancs ou derrière vous restent hors du cône. Remplace la riposte offensive Contre de Justice. Règles communes : Après une projection réussie : immunité aux repoussements de 10 s, commune à toutes les classes ; les tentatives bloquées ne la prolongent pas. La projection interrompt une action interruptible, sans étourdissement supplémentaire à l’arrivée. Préparation esquivable ; un blocage frontal réussi annule le déplacement. Les ancrages réduisent la distance de 70 % (8 m deviennent 2,4 m). Arrêt contre les obstacles sans dégâts de collision supplémentaires ; rebords exploitables uniquement là où la carte autorise les chutes. Boss immunisés : dégâts appliqués, sans déplacement ni interruption automatique. GCD : 1,25 s.

Référence : niveau 30, équipement standardisé, PO = 1000. Dégâts par cible : 100 + 0,20 × PO = 300 bruts. Les valeurs sont des hypothèses de prototype et nécessitent simulation et tests en jeu. Validation de conception V0.2 le 23 octobre 2026 ; aucune implémentation Unity comprise.
