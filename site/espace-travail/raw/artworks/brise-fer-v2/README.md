# Brise-Fer — planche V2

Révision visuelle demandée le 26 octobre 2026. Le novice porte une tenue simple ; le maître des plates massives, un casque et un marteau monumental. Les six skins changent de silhouette, matières, casques et marteaux ; aucune statistique ou règle de classe modifiée.

Sources PNG et référence V1 conservées avec leurs empreintes. Le séparateur horizontal est à y=492 sur 1024 ; découper à 512 couperait les casques de la deuxième rangée. Les détails proviennent du maître de base (colonne VI). `artworks/all-peoples-v1/jobs.json` et son résultat Brise-Fer pointent vers cette version ; les originaux V1 restent conservés.
