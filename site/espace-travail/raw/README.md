# Ashenfall-Knowledge
Base de connaissances et lore officiel du MMORPG Ashenfall

## Équilibrage des classes

La procédure réutilisable pour toute demande d’équilibrage est dans [docs/EQUILIBRAGE.md](docs/EQUILIBRAGE.md), référencée par [AGENTS.md](AGENTS.md). Le dossier `balance/` inventorie les 24 classes et les données manquantes ; `scripts/balance.py` fournit un banc déterministe expérimental et des formules vérifiables, sans dépendance supplémentaire. Les coefficients proposés ne sont ni validés ni publiés automatiquement.
